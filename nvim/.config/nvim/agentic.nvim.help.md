# agentic.nvim 使用指南

适用于本机 Neovim 0.12.5、agentic.nvim `4750d6c`、Codex ACP 2.6.0。默认右侧是对话区，下方是输入框。

## 第一次提问

1. 在代码里按 `v` 选中一段，或按 `V` 按行选中。
2. 依次按 **空格、a、a**，侧栏会带上选区。普通模式下这样打开，会带上当前文件。
3. 在输入框写「解释这段代码」，按 **Ctrl+s** 发送。发送后光标跳到对话区。
4. 读完按 **`i`**，直接回输入框继续写。暂时收起侧栏按 **`Esc` → `空格 at`**，再按 `空格 at` 回到同一会话。

`空格 ac` 表示依次按空格、`a`、`c`。`\m` 表示依次按反斜杠和 `m`。普通模式快捷键可先按 `Esc` 再用，大写字母要按 Shift。

## 打开、发送、停止

| 操作 | 按键 |
| --- | --- |
| 打开对话并带上当前文件或选区 | `空格 aa` |
| 收起／展开侧栏，会话在后台保留 | `空格 at`。在侧栏里也可按 `q` 收起 |
| 输入多行 | 输入时按 `Enter` 换行 |
| 发送输入框内容 | `Ctrl+s`，或在输入框按 `Esc` → `Enter` |
| 停止本轮生成，保留会话 | `空格 aS`（大写 S） |

## 移动光标、阅读对话

| 从哪里到哪里 | 操作 |
| --- | --- |
| 输入框 → 上方对话区 | `Esc` → `Ctrl+w` → `k`。中间有附件或任务面板时，重复 `Ctrl+w` → `k` |
| 对话区 → 输入框 | 普通模式按 `i`，立即开始输入 |
| 侧栏 → 左侧代码 | `Ctrl+w` → `h`。从代码向右回侧栏用 `Ctrl+w` → `l` |
| 下一段／上一段对话标题 | `]]` ／ `[[` |
| 下一次／上一次工具调用 | `]t` ／ `[t` |
| 展开／收起一段工具输出 | 光标放在折叠处按 `za`。全部展开用 `zR`，全部收起用 `zM` |
| 查看最新回复、搜索、复制 | `G` 到末尾，`/关键词` 回车搜索，`V` 选行后按 `y` 复制 |

## 给 Codex 提供上下文

| 想加入什么 | 操作 |
| --- | --- |
| 当前文件或一段代码 | 在代码区按 `空格 ac` 加当前文件。先用 `v` 或 `V` 选中再按，只加选区 |
| 项目里的其他文件 | 在输入框行首或空格后输入 `@文件名`，用 `Ctrl+n`／`Ctrl+p` 选候选，`Tab` 确认。可连续引用多个文件 |
| 截图 | 复制图片后，在输入框普通模式按 `\p`，或输入时按 `Ctrl+v` |
| 当前行的诊断 | 在代码区执行 `:lua require('agentic').add_current_line_diagnostics()` |
| 当前文件的全部诊断 | 在代码区执行 `:lua require('agentic').add_buffer_diagnostics()` |
| 移除已添加的条目 | 到侧栏的文件、选区或诊断列表，在条目上按 `d`。也可用 `V` 选多行后按 `d` |

## 模型、思考强度、模式

在侧栏按 `Esc` 后操作。先换模型，再选该模型支持的思考强度。

| 按键 | 作用 |
| --- | --- |
| `\m` | 选择当前会话的模型，回车确认，保留对话历史 |
| `\t` | 选择思考强度。本机 `gpt-6.1-sol` 提供 `low`、`medium`、`high`、`xhigh`、`max`、`ultra`，其他模型以菜单为准 |
| `\o` | 查看会话选项和当前值。在选项行按 `Enter` 修改，`q` 或 `Esc` 关闭 |
| `Shift+Tab` | 选择 agent 工作模式，可用项由 Codex 提供 |
| `\s` | 切换到其他已安装的 ACP 提供方 |

## 审批、看改动

- 出现权限请求时，在对话区的按钮行用 `h`／`l` 选择允许或拒绝，再按 `Enter`。也可直接按按钮显示的数字。多个待审批请求用 `Ctrl+n`／`Ctrl+p` 切换。
- 出现并排 diff 预览时，`]c` 跳到下一处改动，`[c` 跳到上一处。
- 修改写入后，在受 Git 跟踪的文件里按 `空格 hp` 预览光标处的改动，或按 `空格 hd` 与暂存区比较。看整个仓库按 `空格 hs`。

## 新建、切换、恢复会话

| 操作 | 按键 |
| --- | --- |
| 新建对话 | `空格 an`，或在输入框发送 `/new`。已有会话时，选 `Keep current session in the background` 可让它留在后台 |
| 列出本次 Neovim 中仍开着的会话 | 在侧栏按 `\l`（小写 L），选中后回车 |
| 下一个／上一个会话 | 在侧栏按 `\]` ／ `\[` |
| 恢复以前的 Codex 对话 | `空格 ah`，从当前项目的历史中选择，包括在终端开始的会话 |
| 结束当前活动会话并移除侧栏 | 在侧栏按 `\D`（大写 D），立即生效。只想收起时用 `q` |

## 其他常用入口

- 在输入框键入 `/` 查看当前可用命令。Codex ACP 提供 `/status` 查看状态、`/compact` 压缩上下文、`/review` 发起代码审查。
- 用 `:lua require('agentic').rotate_layout()` 切换侧栏位置，按右侧、底部、左侧循环。
- 连接或粘贴图片异常时，运行 `:checkhealth agentic` 检查依赖，用 `:messages` 看最近报错。
- 用 `:help agentic.nvim` 打开内置帮助，`:help agentic-keymaps` 查看完整键位。重开本指南用 `:e ~/.config/nvim/agentic.nvim.help.md`。
