# lualine 状态栏与通知

Neovim 0.12.5 · lualine.nvim `221ce6b`。编辑器底部的状态栏随当前窗口更新。日常阅读时，直接看对应位置即可。

| 位置 | 本机显示 |
| --- | --- |
| 左侧 | 编辑模式、Git 分支，以及用 `+`、`~`、`-` 表示的新增、修改、删除行数 |
| 中间 | 当前工作目录和文件路径。文件名旁的 `●` 表示有未保存的修改，锁形图标表示只读 |
| 右侧 | 错误、警告、信息和提示（`E`、`W`、`I`、`H`），随后是文件类型、阅读进度和行列位置 |

如果 lualine 提示配置有问题，执行 **`:LualineNotices`** 打开详情，在该窗口普通模式按 **`q`** 关闭。这个命令在插件有通知时才会出现。

要查看状态栏所示 Git 改动的具体内容，回到文件按 `空格 hp`。[Gitsigns 快捷键](gitsigns.nvim.help.md)
