# Snacks 文件树与预览

Neovim 0.12.5 · snacks.nvim `882c996`。在普通模式依次按 **空格、e** 打开左侧项目树。用 `j`、`k` 找到文件，按 `Enter` 打开。文件树会保留并跟随当前文件。

## 在项目树中

| 要做什么 | 按键 |
| --- | --- |
| 打开文件、展开目录 | `Enter` 或 `l`。`h` 收起目录，`Z` 收起全部目录 |
| 查找树中的文件 | `/` 进入搜索框，输入文件名。要搜文件内容，在树里按 `空格 /` |
| 改变树的根目录 | `.` 聚焦光标所在目录，`Backspace` 上移一级 |
| 查看隐藏或忽略的文件 | `H` 切换隐藏文件，`I` 切换 Git 忽略项 |
| 预览、分屏打开 | `P` 切换预览。`Ctrl+v` 竖分屏打开，`Ctrl+s` 横分屏打开 |
| 查找改动或诊断 | `]g`／`[g` 到后一处／前一处 Git 改动。诊断用 `]d`／`[d`，仅错误用 `]e`／`[e` |
| 刷新、看键位、关闭 | `u` 刷新树，`?` 查看树内键位，`q` 关闭 |

## 新建、移动、复制

- 按 `a` 输入新文件名，目录名末尾加 `/`。`r` 重命名，`d` 删除当前项或已选项。
- 批量移动时，先在每个源文件上按 `Tab` 选中，再走到目标目录按 `m`。批量复制用同样步骤，最后按 `c`。
- 也可以用 `y` 复制所选文件的路径，到目标目录按 `p` 粘贴文件。`o` 用系统应用打开当前文件。

## 图片、Mermaid 与 PDF

- 在 Markdown 中把光标放到图片链接或 Mermaid 代码块上，普通模式依次按 `\i` 预览。图形显示取决于终端支持，Mermaid 还需要 `mmdc`。
- 打开 PDF 后按 `\t`，本机配置会调用 `pdftotext` 打开只读文本。用 `/关键词` 搜索，选中文字按 `y` 复制，`q` 关闭文本视图。

内置帮助见 `:help snacks-explorer` 和 `:help snacks-image`。
