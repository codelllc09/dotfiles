# Neogit 仓库状态与提交

Neovim 0.12.5 · Neogit `ba2f33b6`。普通模式依次按 **空格、h、s** 打开仓库状态页。以下单键从状态页开始。

## 提交一次修改

1. 用 `j`／`k` 移到 `Unstaged changes` 下的文件。按 `Tab` 展开 diff。
2. 在文件名上按 `s` 暂存整个文件，在展开的改动块上按 `s` 暂存该块。要撤回暂存，在 `Staged changes` 中按 `u`。
3. 依次按 `c c` 打开提交信息编辑器。写好后连按两次 `Ctrl+c` 提交。要取消，按 `Ctrl+c` 再按 `Ctrl+k`。

## 状态页速查

| 操作 | 按键 |
| --- | --- |
| 展开／收起文件、改动或区段 | `Tab` 或 `za`。`1` 到 `4` 调整整页展开层级 |
| 跳到上一个／下一个改动块或区段 | `{`／`}` 跳改动块，`Ctrl+p`／`Ctrl+n` 跳区段 |
| 打开光标处文件 | `Enter`。`Ctrl+v` 竖分屏，`Ctrl+x` 横分屏，`Ctrl+t` 新标签页 |
| 暂存／撤回暂存部分行 | 在展开的 diff 里用 `V` 选中改动行，然后按 `s`／`u` |
| 丢弃工作区改动 | 在目标文件或改动块上按 `x`，核对范围后确认。要保留内容、仅撤回暂存，用 `u` |
| 看历史 | `l l` 打开当前分支日志。在状态页按 `$` 查看 Neogit 执行过的 Git 命令 |
| 刷新、查看操作、关闭 | `Ctrl+r` 刷新，`?` 打开帮助菜单，`q` 关闭状态页 |

## 分支与远程

`b` 打开分支菜单，`f` 抓取（fetch），`p` 拉取（pull），`P` 推送（push），`Z` 打开 stash 菜单。这些键先打开菜单，再按界面列出的键选择目标和操作。

内置帮助见 `:help neogit`。
