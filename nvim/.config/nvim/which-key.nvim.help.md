# which-key 快捷键提示

Neovim 0.12.5 · which-key.nvim `3aab214`。普通模式按一下 **空格**，停约 0.3 秒，就能看到当前位置可接着按的键。

| 想做什么 | 怎么按 |
| --- | --- |
| 找 Git 操作 | 依次按 `空格 h`，稍等看第二层菜单。例如再按 `s` 就会打开 Neogit |
| 找 Codex 操作 | 依次按 `空格 a`，稍等查看打开、收起、新建等操作 |
| 执行提示中的动作 | 直接按该项显示的字母。大写字母要按 Shift |
| 返回上一级／取消整串按键 | `Backspace` 返回，`Esc` 取消 |
| 提示窗口翻页 | `Ctrl+d` 向下，`Ctrl+u` 向上 |

提示会随窗口和模式变化。例如在 Gitsigns 已附加的文件里，`空格 h` 下才会出现预览当前改动块的 `p`。已记住的组合可以直接连按，不必等菜单弹出。

要追查某个键的实际绑定，在目标窗口执行 `:verbose nmap <Space>hp`。插入模式用 `:verbose imap`。插件帮助见 `:help which-key.nvim.txt`。
