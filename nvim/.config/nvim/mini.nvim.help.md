# mini.nvim 编辑与查找

Neovim 0.12.5 · mini.nvim `d79805a`。下列 `空格 f` 等组合依次按键，大写字母区分大小写。

## 找文件、搜内容、切缓冲区

| 普通模式入口 | 用途 |
| --- | --- |
| `空格 f` | 按文件名模糊查找 |
| `空格 g` | 在当前工作目录实时搜索文件内容，默认用正则。`Ctrl+e` 切换纯文本／正则，`Ctrl+o` 限制文件范围，如 `*.lua` |
| `空格 b` | 搜索并切换已打开的缓冲区 |

在 MiniPick 窗口直接打字筛选。`Ctrl+n`／`Ctrl+p` 下选／上选，`Tab` 开关预览，`Shift+Tab` 看键位和信息。`Enter` 打开结果，`Ctrl+v` 竖分屏、`Ctrl+s` 横分屏、`Ctrl+t` 新标签页打开。`Esc` 退出。用 `Ctrl+x` 标记多个结果，`Alt+Enter` 处理已标记项。

## 像编辑文本一样整理文件

1. 按 **空格、Shift+e**（`空格 E`）打开 MiniFiles，定位到当前文件。`j`／`k` 选条目，`l` 进入目录或打开文件，`h` 返回上级。在文件上按 `L` 打开文件并关掉 MiniFiles。
2. 在目录列表里按 `o` 新起一行写文件名，目录名末尾加 `/`。改名字就编辑该行。`dd` 移除一行，`yy`、`p` 可以跨目录复制，`dd`、`p` 可以跨目录移动。
3. 按 **`=`** 查看待执行的文件操作，确认后才写入磁盘。确认删除会永久删除对应文件。`g?` 看帮助，`q` 关闭。

## 加括号、换引号

| 操作 | 示例 |
| --- | --- |
| 给当前词加圆括号 | 普通模式依次按 `saiw)`，把 `name` 变成 `(name)` |
| 给选区加双引号 | 先用 `v` 选中，再依次按 `sa"` |
| 去掉一对双引号 | 光标在引号内，依次按 `sd"` |
| 把双引号换成单引号 | 光标在引号内，依次按 `sr"'` |
| 找出当前词外的括号 | `sh)` 短暂高亮这对括号，`sf)`／`sF)` 跳到右／左边界 |

输入模式下输入左括号会自动补右括号。在成对的空括号中按 `Backspace` 会一起删除，在已有右括号前再输入同一右括号会越过它。

## 快速跳转与清理

- `空格 j` 显示可见位置的字母标签。按目标字母跳转，重复标签继续按提示缩小范围，`Esc` 取消。
- 普通模式用 `]b`／`[b` 切下一个／上一个缓冲区，`]d`／`[d` 跳诊断，`]q`／`[q` 跳 quickfix 条目，`]x`／`[x` 跳合并冲突标记。
- MiniTrailspace 高亮行尾多余空格。执行 `:lua MiniTrailspace.trim()` 清理当前缓冲区，再用 `:w` 保存。

内置帮助见 `:help MiniPick`、`:help MiniFiles`、`:help MiniSurround` 和 `:help MiniBracketed`。
