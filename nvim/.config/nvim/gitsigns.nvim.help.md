# Gitsigns 文件改动速查

Neovim 0.12.5 · gitsigns.nvim `1e9d0fb`。在已附加 Gitsigns 的文件里使用普通模式。左侧 `+`、`~`、`-` 分别表示新增、修改和删除。相邻的改动行构成一个改动块（hunk）。

## 阅读改动

| 要做什么 | 按键 |
| --- | --- |
| 跳到下一处／上一处改动 | `]c`／`[c`。在 diff 分屏里使用 Neovim 的差异跳转 |
| 弹窗看光标处的改动 | `空格 hp` |
| 在正文中预览该改动块 | `空格 hi` |
| 看当前行由谁、在哪次提交修改 | `空格 hb` |
| 比较当前文件和 Git 暂存区 | `空格 hd` |
| 比较当前文件和 `HEAD~1` | `空格 hD`，最后的 D 大写。若要与当前提交本身比较，用 `:Gitsigns diffthis HEAD` |

例如先按 `]c` 跳到一处修改，再按 `空格 hp` 查看删掉的旧行。比较分屏用 `Ctrl+w` 再按 `w` 在两侧切换，在比较窗口执行 `:close` 即可关闭该窗。

## 暂存改动

- 在改动块内执行 `:Gitsigns stage_hunk` 暂存该块。
- 要逐项检查整个仓库，按 `空格 hs` 打开 [Neogit 状态页](neogit.help.md)，在那里用 `s` 暂存、`u` 撤回暂存。

内置帮助见 `:help gitsigns`。
