# 用 Treesitter 折叠代码

Neovim 0.12.5 · nvim-treesitter `a2f6944`。插件提供语言解析器，当前配置按语法结构折叠代码。打开文件时默认全部展开，下面用的都是 Neovim 普通模式折叠键。

| 想做什么 | 按键 |
| --- | --- |
| 切换光标所在折叠 | `za` |
| 收起／展开一层 | `zc`／`zo` |
| 连同嵌套结构一起收起／展开 | `zC`／`zO` |
| 收起／展开整个窗口的折叠 | `zM`／`zR` |
| 跳到下一折叠的开头／上一折叠的末尾 | `zj`／`zk` |

读长文件时，先按 `zM` 看结构，移到目标函数按 `zo` 展开一层，或用 `zO` 展开整个函数。折叠只影响当前窗口的显示。

光标处没有可折叠内容时，可执行 `:setlocal foldmethod? foldexpr?`。启用本配置的语法折叠时会看到 `expr` 和 `v:lua.vim.treesitter.foldexpr()`。可折叠区域还取决于该语言的折叠规则。完整键位见 `:help fold-commands`。
