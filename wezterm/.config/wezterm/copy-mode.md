# 复制模式 / 搜索模式 · 操作手册

> 2026-09-09 定稿。键位实现:`copy_keys.lua`(冻结默认表 + 增补,改动历史和
> 本 nightly 的坑全记录在该文件注释里);进入器在 `wezterm.lua` 的
> `enter_copy_mode_clean`。忘了就翻这页。

## 总览

**三层心智模型(2026-09-09 定稿)**:

- **常态 = 输入模式**(readline/命令模式):所有按键都发给程序,任何输入自动
  拉回底部——所以常态下键盘翻不了页(PageUp/Down 和滚轮除外)
- **复制模式 = 浏览模式**:想自由翻页看回滚,就进这层。纯浏览(不抄)也是它:
  Ctrl+Shift+X → m/g 翻 → Q 留原位 → 打个字回家。不另造独立浏览模式——
  功能完全重合,多一个键表在这个 nightly 上就是多一份翻车面
- **搜索态 = 复制模式的查找子层**,Esc 摆渡

```
普通模式 ── Ctrl+Shift+X ──► 复制模式(阅读室/浏览模式)◄── Esc ──► 搜索态
                                │  Q = 唯一出口        │
                                └──── Tab/Esc 落位 ◄───┘
```

- 右下角徽章:`COPY-MODE` / `SEARCH-MODE`(黄色)= 当前所在层,迷路时看它
- **Esc 永远只在复制⇄搜索间摆渡**,从不退出、从不取消选区
- **出口唯一:`Q`**(Shift+Q);`q` / `:` / Ctrl+G / Ctrl+C 全部吞掉
- 复制只发生在复制模式里,唯一的键是 `y`

## 复制模式(阅读室)

| 键 | 作用 |
|---|---|
| `v` / `V` / `Ctrl+V` | 字符 / 行 / 块选区;**再按 v 取消** |
| `h j k l` / 方向键 | 移动 |
| `w` `b` `e` | 词跳(前/后/词尾) |
| `0` / `^` / `$` | 行首 / 首字符 / 行尾 |
| `Ctrl+A` / `Ctrl+E` | 行首 / 行尾(readline 习惯) |
| `n` / `m` | 下 / 上**半屏**(u i o p 空间簇的传统位置) |
| `Ctrl+u` / `Ctrl+d` | 上 / 下半屏(默认,vim 习惯) |
| `g` / `G` | 回滚区顶 / 底 |
| `f`·字符 / `F`·字符 | 行内跳到字符(向前/向后);`;` 重复 `,` 反向 |
| `o` | 光标跳到选区另一端(扩选前先按它) |
| **`y`** | **抄 + 关选区 + 留任**(高亮消失 = 复制回执) |
| `/` 或 `Esc` | 进搜索态 |
| **`Q`** | **退出**(留在原位,顺带清搜索词) |

## 搜索态

| 键 | 作用 |
|---|---|
| 直接打字 | 输入搜索词(子串即可) |
| `Enter` / `↑` | 跳到最近匹配 / 上一个 |
| `↓` | 下一个匹配 |
| `Ctrl+U` | 清空搜索词 |
| `Ctrl+R` | 切换匹配类型(大小写敏感/正则) |
| **`Esc`** | **干净落位**:回复制模式,光标在匹配处,**无选区**(自己 v 选) |
| **`Tab`** | **带选落位**:回复制模式,匹配词已选中 → 直接 `y` 抄整词 |

## 典型流程

```
手选抄      Ctrl+Shift+X → v → 移动 → y → 继续 → Q
跳转抄      Ctrl+Shift+X → / → 词 → Enter → Esc → v → 移动 → y → Q
整词直取    Ctrl+Shift+X → / → 词 → Enter → Tab → y → Q
直接搜索    Ctrl+Shift+F(原地,不进复制模式)→ 词 → Enter → Esc(落位进复制模式)→ …
回家        Q 之后按 Down 或任意输入;显式键 Ctrl+Shift+End(顶:Ctrl+Shift+Home)
```

## 设计原则(为什么长这样)

1. **阅读室哲学**:模式内视口完全受控(Down 只移光标不拉底);所有退出留原位
2. **y 关选区**:高亮消失是唯一可用的复制反馈;旧选区残留会造出「隐藏锚点」
   (以为在重新选,实际在收窄旧选区)——这坑踩过两次,结构性堵死
3. **出口唯一(Q)**:`q` 紧邻 `w`(词跳)易误触;曾试 `:q` 时间戳(无反馈)、
   `:` 输入框(本 build 组件阵亡),定稿 Shift+Q——防误触零机制依赖
4. **搜索态纯导航**:复制键在搜索态被吞(普通 y 会打进搜索框)——想抄?
   Esc 落位再说
5. **视口不动的底气**:退出后 Down/输入自动回底,所以不需要专门滚底习惯

## 注意事项

- **原地進入（2026-09-09）**：常態下翻著回滾按 `Ctrl+Shift+X` / `Ctrl+Shift+F`，視口
  不再被拉回底部，且**光標投到視口中間**（等效進層即按 `M`——不然光標留在底部
  提示符處，按任何移動鍵都會被拽回底部）。真兇是按 tab 記憶的舊搜索詞
  （SAVED_PATTERN）在開層時自動復活並跳最底匹配，以及光標初始化在 pane 真實
  位置——上游進層本就繼承視口。現在常態進入一律清詞：`Ctrl+Shift+X` 進入後
  `/` 開空欄（與「Q 清詞」哲學一致）；複製模式會話內 `/` 和 `Ctrl+Shift+F`
  仍保留舊詞。搜索態打字後 350ms 跳到匹配是增量搜索本義，保留

- 搜索态里**别按 `y`**(会打进搜索框);Ctrl+Y 也被吞了,复制一律落位后做
- 落位后想扩选:**先 `o` 再向右移**(向左移会收窄选区)
- 这个 nightly 上改 copy_keys.lua 的铁律见文件头注释:层切换绝不组合动作、
  键表整表替换后必须 show-keys 全量对账、wezterm.action 是严格 userdata

## 附录:与 Vim 四模式的对应(2026-09-09)

| Vim | 我们 | 对应度 |
|---|---|---|
| Normal(移动/删改/复制) | 复制模式(hjkl、w/b、g/G、f) | 移动全家桶逐键对应;**只有 y,没有 d/c/x** |
| Insert(输入) | 常态(打字给程序) | 完全对应——但「家」相反:vim 的家是 Normal,我们的家是输入态,所以 Esc 语义是「向阅读摆渡」而非「回家」 |
| Visual(v/V/Ctrl+V) | 复制模式内 `v`/`V`/`Ctrl+V` | 逐键一致(含块选);但选后只能 y |
| Command-line(`:`/`/`) | 搜索态(`/`)+ `Q` 退出 | `/` 对应;`:` 命令族只救回 `:q`(输入框组件在本 build 阵亡) |

**两个原理性缺口(终端本质决定,非缺陷)**:

1. **删改不可能**——vim 拥有自己的可写缓冲;终端回滚区是程序(pi/shell)
   画布的只读历史快照。d/c/x、`:s`、`:w` 永远无对应,要改文本回程序里改
2. **Insert 地位相反**——终端与程序持续对话(输入密集),翻看才是间歇;
   vim 正好倒过来。所以我们的模态是「输入态 + 阅读逃逸层」,
   vim 是「编辑态 + 输入逃逸层」

**完整对应其实是嵌套的**:终端里跑真 vim 时,vim 四模式整个住在
我们「常态」里——

```
常态(wezterm 的 Insert) ⊃ 程序 ∋ { vim 的 Normal/Insert/Visual/Cmdline }
复制模式 = 逃逸到缓冲视图层,对程序画过的文本做只读操作(移/看/选/抄)
```
